# RATDOG - Skadedjursbekämpning

Hemsida för ratdog.se - skadedjursbekämpning under modellen "No Kill No Pay"

## Beskrivning

RATDOG erbjuder professionell skadedjursbekämpning för råttor, möss och sorkar med en unik prismodell:
- **Ingen fångst = 0 kr**
- **Per gnagare = 50 kr**

## Användning

1. Klona repot
2. Öppna `index.html` i en webbläsare
3. Eller distribuera på GitHub Pages eller vilken webbserver som helst

## Deployment på GitHub Pages

1. Gå till Settings → Pages
2. Välj "Deploy from a branch"
3. Välj `main` branch och `/root` folder
4. Spara - sidan blir tillgänglig på https://ratdog617.github.io/ratdog-website/

## För att koppla till din egen domän (ratdog.se)

1. Uppdatera DNS-inställningarna hos din domänregistrator
2. Lägg till en CNAME-post som pekar till `ratdog617.github.io`
3. Lägg till domänen i GitHub Pages inställningar

## Struktur

- `index.html` - Huvudsidan
- `style.css` - Stilar
- `script.js` - JavaScript-funktionalitet

## Kontakt

Uppdatera telefonnummer och e-post i `index.html` med dina verkliga kontaktuppgifter!
